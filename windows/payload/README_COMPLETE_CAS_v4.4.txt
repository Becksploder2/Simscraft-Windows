SimMorph Studio v4.4 — Complete CAS Studio (Windows)

New: Complete CAS Studio menu with 13 guided CAS appearance categories and Export Complete CAS Plan.
Existing features preserved: reference import, 38 face templates, theme switcher, CAS capture, body guides, one-click CAS bridge and optional face analysis setup.

The Complete CAS Studio categories are guided/manual. This version does NOT automatically select CAS catalog items, change clothing, detect glasses or teeth from photos, or morph the entire body.
Face analysis still requires an installed compatible MediaPipe runtime and model; it is NOT bundled as a working offline engine.
The Sims 4 must be installed and running for game interaction. Test with a disposable Sim.
Windows binary cross-compiled, not Windows runtime-tested.
