CASCraft Studio v4.5 — Glasses Creator prototype
Open CASCraft Creator (Prototype) > Open Glasses Creator.
Imports a reference photo, draws editable 2D glasses, exports transparent PNG and design JSON.
NOT photo-to-3D, automatic photo matching, or Sims 4 .package export.
The PNG is a design concept, not a Sims 4 CAS texture map.
Windows app cross-compiled; macOS Swift source is provided uncompiled/untested.
