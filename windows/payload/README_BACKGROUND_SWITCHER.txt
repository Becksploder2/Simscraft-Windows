SimMorph Studio v3.8 - Background Switcher

Open Change Background in the menu bar to choose a background.
Import Background copies a PNG, JPG, JPEG or BMP into Backgrounds and activates it.
To add images manually, copy them to Backgrounds, then choose Refresh Background List.
The last selected background is saved in Config/selected_background.txt.
Default CAS Room always uses the original assets/cas_room.bmp.

Face recognition and automated in-game CAS morphing still require the missing inference runtime/model and calibration.
