SimMorph Studio v2.2 CAS screenshot capture

Import a photo using the v2.0-derived picker. In The Sims 4 CAS, ensure the Sim is facing forward and the game is visible. Click Capture Current CAS Face, then switch to The Sims 4 within three seconds. The app captures the current Sims 4 window to Captures/current_cas.png.

This is an initial screenshot baseline, NOT a trained facial landmark detector or automatic morphing system. A face-region crop, landmark runtime, and CAS calibration are still needed. Captures can include game UI and other on-screen content.
