CASCraft Studio v4.7 — Windows

Run CASCraftStudio.exe from this folder. Open SmartMorph v4.7 > Open SmartMorph / Photo Studio.
The photo workspace opens in your default web browser and works offline.

Working: photo import, optional quality enhancement, 5 separate framing tabs, manual face focus, browser-dependent automatic face framing, zoom, image export, and JSON SmartMorph plan.
Not working yet: real photo-to-template scoring, face-slider inference, automatic Sims 4 sculpting, or Sims 4 CC .package generation.

Windows executable cross-compiled on Linux; not runtime-tested on Windows.
